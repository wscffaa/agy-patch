# Cookbook

English | [中文](README.zh.md)

Step-by-step how-tos. Each guide is a numbered procedure ending in verify steps, and links the Agent Note that holds its design rationale. A cookbook does not carry design rationale or type definitions; link to their homes.

## Guides

| Guide | Use when |
|---|---|
| — | No guides yet. Add one when a procedure repeats across changes. |

## Writing a guide

1. Start with the outcome in one sentence.
2. List prerequisites, then numbered steps. Each step is one action.
3. End with verify steps that prove the outcome.
4. Link the Agent Note that explains the decision behind the procedure.
