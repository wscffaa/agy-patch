# 操作手册

[English](README.md) | 中文

分步操作指南。每份指南是一个带编号的流程，以验证步骤结束，并链接保存其设计理由的 Agent Note。操作手册不承载设计理由或类型定义；请链接到它们各自的归属文档。

## 指南

| 指南 | 适用场景 |
|---|---|
| — | 暂无指南。当某个流程在多次变更中重复出现时再添加。 |

## 撰写指南

1. 用一句话写明结果。
2. 列出前置条件，然后是带编号的步骤。每步只做一个动作。
3. 以能证明结果的验证步骤结束。
4. 链接解释该流程背后决策的 Agent Note。
