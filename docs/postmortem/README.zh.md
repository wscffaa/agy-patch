# 事故复盘

[English](README.md) | 中文

事故记录：某个缺陷到达了不该到达的地方（真实用户、已合并的 PR、一次发布），而有价值的部分是*为什么我们的流程放行了它*，而不只是那一行修复。

事故复盘不是 [Agent Note](../../.agents/notes/README.zh.md)。Agent Note 记录有意的设计决策或未来工作的提案；事故复盘是对失败的回顾性记录：什么坏了、机制是什么、每道安全网为何都没拦住、以及新增了哪些护栏，使同类缺陷下次能够大声失败。

当缺陷**隐蔽**（机制不直观）、**系统性**（逃逸原因是测试、工具或约定上的缺口，而非一次性笔误）、并且**重新发现代价高**时才需要撰写。链接本次复盘促成的护栏（测试、AGENTS.md 规则、Agent Note）。

每篇复盘以**执行摘要**开头：一段简短文字，让忙碌的读者在三十秒内读懂。它说明什么坏了、根因的平白表述、逃逸原因以及可长期保留的教训。随后是详细章节（摘要、时间线、根因、护栏）。
